# ViraShorts AI Android starter — voice/storyboard update

## Included
- Android app home UI and navigation
- Story input
- Story splitting into up to 12 storyboard scenes
- On-device Android TextToSpeech voice preview (Hindi/English/Hinglish, depending on voices installed on the phone)
- Stop voice playback

## Build
Open this folder in Android Studio, sync Gradle, then run on an Android device/emulator.

## Important limitations
This is not yet a full AI text-to-video generator and does not export MP4 files.
The voice preview uses Android's installed TextToSpeech engine; availability and voice quality
depend on the device and installed language data. No external paid API is used by this feature.
Real AI video generation needs a model running on a server/device or a video-generation provider.
A genuinely unlimited service cannot be promised at zero cost because compute, storage and bandwidth
are finite and have operating costs.
